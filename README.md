# Daymark Start

黑色极简浏览器新标签页。时间、日期、搜索和常用网址居中；DayMark 显示现在该做什么；AIHOT 显示前三条热点。

## 安装（Edge / Chrome）

1. 从 [GitHub Releases](https://github.com/Raymond-Specter/daymark-start/releases/latest) 下载 `daymark-start-版本号.zip` 插件包并解压，或下载源码。
2. 打开 `edge://extensions` 或 `chrome://extensions`，启用「开发人员模式」。
3. 点击「加载解压缩的扩展」。源码选择 **extension** 文件夹；独立插件包选择解压后直接包含 **manifest.json** 的目录（不能直接选择 ZIP）。
4. 打开新标签页。如果浏览器询问是否保留新标签页更改，选择保留。

这是 Manifest V3 插件，无构建步骤，无生产依赖。GitHub 源码发布不等于扩展商店上架；尚未上架商店。

Windows 下运行 `powershell -NoProfile -File tools/Package.ps1`，会生成版本化 ZIP、SHA256 校验文件和 `artifacts/daymark-start.zip`，可用于本地安装及商店上传。正式上架的账号、文案、权限说明、素材和审核步骤见 [STORE.md](STORE.md)。数据处理方式见 [隐私说明](PRIVACY.md)。

## 配色方案

右下角设置里提供五套预设：午夜黑（默认）、纸白、海军蓝、森林绿、暖咖棕。小色卡展示底色、层次色和强调色；点选立即应用到整个首页并自动记住，关闭设置、刷新或打开新标签页后仍保留。搜索引擎、网址等其他设置仍需点击「保存设置」。旧版已保存的配色会继续保留。

界面支持轻微回弹、按压反馈、搜索框悬停与聚焦、DayMark 小栏目浮起和描边、热点标题滑动与箭头反馈、设置面板展开/收起和背景配色淡化。使用系统默认鼠标，输入区保留文字光标；系统启用「减少动态效果」时自动停用动画。旧浏览器可直接切换配色。

背景加入跟随主题的低强度微光与 2% 静态噪点；搜索、网址图标和 DayMark 卡片使用轻磨砂表面与顶部亮边。噪点随插件本地提供，背景没有持续动画；不支持背景模糊的浏览器使用不透明表面。

## 翻页番茄钟

点击首页时间，直接开始默认 25 分钟的全屏翻页倒计时。默认时长可在右下角设置中改为 1–99 的整数分钟，保存后用于下一次新计时。计时页沿用当前配色，只显示大号 `MM:SS`；暂停与返回按钮在移动鼠标、触屏或键盘操作时出现，静置 2.2 秒隐藏。

- 空格暂停 / 继续；到零后空格重新开始一轮。
- Esc 或返回按钮退出并暂停，再次点击时间可继续；修改默认时长后会开启新时长。
- 运行中的计时按结束时间校准，切到后台或刷新后仍能恢复本标签页的进度；关闭标签页后不提供后台提醒。到零后保持 `00:00`，无声音、通知或自动切换休息阶段。

系统启用减少动态效果时数字直接更新。浏览器拒绝全屏或嵌入式预览不允许全屏时，仍提供铺满网页的计时界面。刷新恢复无法自动请求浏览器全屏，需要用户之后重新进入。默认时长保存在本机设置；当前计时仅保存在当前标签页的 sessionStorage，不上传或跨标签页同步。

## DayMark 连接

在右下角设置里填写 [DayMark](https://github.com/Raymond-Specter/DayMark) 的网页根地址，例如 `http://127.0.0.1:3000`。远程站点使用 HTTPS。插件只申请指定域名的访问权限，端口权限遵循 Chromium 的站点匹配规则。切换服务器后可在浏览器的扩展权限设置里撤销旧站点授权。

读取现有 `GET /api/today` 和 `GET /api/settings`，依据 DayMark 的时区选择任务：

- 优先当前时间段内尚未完成且未被依赖阻塞的任务；多项重叠按优先级、开始时间选一项。
- 无当前任务时，显示今天下一项有时间安排的任务。
- 再显示今天无时间安排的待办；最后显示错过时间但未完成的任务，标为「待处理」。
- 完成、取消、其他日期、等待前置任务的事项不会被推荐为当前任务。
- 下一项显示今天下一项有时间安排的可执行任务。

页面可见时每分钟刷新，切回标签页时重新读取。任务只保留在页面内存中，不上传到 GitHub、不存入永久缓存。未连接、登录失效和服务不可用均明确显示状态，不以示例任务充当真实数据。

云端沿用网页登录 Cookie，不保存密码或 API Key。请先在同一浏览器的 DayMark 网页登录。如果 Cookie 因浏览器策略未发送，会显示需要登录；当前未在用户实际云端部署上验证。此版本没有完成、延期或其他任务写入按钮。

## AIHOT 热点

使用 [AIHOT 官方公开 API](https://aihot.news/agent)：`GET https://aihot.news/api/v1/hot-topics`。无需注册或 Key。每 5 分钟条件请求，保留 ETag，遵守服务的缓存时长和 Retry-After。不同新标签页通过后台共享请求和本机缓存；不可见页面停止轮询。显示前三条标题、检查时间以及 AIHOT 阅读链接。网络失败时注明缓存状态，无缓存时显示获取失败，不伪造新闻。

本项目是个人首页客户端，直接从 AIHOT 获取数据，不提供代理、公共镜像或新闻数据集。个人非商业使用应遵守 [AIHOT 使用规则](https://aihot.news/terms)；商用产品、付费服务、公开数据再分发等须按其规则取得书面授权。源码公开不代表获得任何用途的数据授权。界面里的来源名称表示数据来自该服务，本项目不代表其官方产品。

## 网页预览与开发

用任意静态服务器服务项目根目录，例如 `python -m http.server 8765 --bind 127.0.0.1`，打开 `http://127.0.0.1:8765/extension/index.html`。加 `?demo=1` 可预览 DayMark 示例任务，栏目会明确标注示例；真实 DayMark 跨站连接需要加载插件。网页预览的 AIHOT 获取还受浏览器 CORS 约束。

`npm test` 使用 Node 内置测试运行器验证时间、任务选择和地址处理，无需 `npm install`。本项目无额外 lint/typecheck/build 命令。功能实现为原生 HTML/CSS/JavaScript。所有脚本和图标随插件打包，不使用远程字体或远程可执行代码。

设计方案与参考见 [DESIGN.md](DESIGN.md)。
