# Bundled fonts

- Outfit: https://github.com/google/fonts/tree/main/ofl/outfit
- Noto Sans SC: https://github.com/google/fonts/tree/main/ofl/notosanssc

Downloaded from the Google Fonts repository on 2026-10-13. Both fonts are distributed under SIL Open Font License 1.1. Their copyright and license notices are preserved in the adjacent `*-OFL.txt` files.

The WOFF2 files are subsets made with FontTools, preserving variable weights and layout features. Outfit retains Latin and punctuation/arrow characters. Noto Sans SC retains Latin, punctuation, full-width characters, Bopomofo and the CJK ranges U+3400–4DBF and U+4E00–9FFF so user-entered task titles render consistently. Remaining characters fall back to system fonts.
